Process

ProcessÉtapes · skill · ce qu'on décide (qui)Derniers passages
installation
operations · à la demande, une fois après le clonage
  1. Préparer son profil, avant l'atelier · grill-me · chaque réponse, ou « À définir » (toi)
  2. Récupérer le socle et déposer le profil dans inbox/ · installation · le dossier où installer (toi)
  3. Reprendre le profil, bloc par bloc · installation · garder ou corriger chaque bloc (toi)
  4. Poser les questions restantes · grill-me · chaque réponse, ou « À définir » (toi)
  5. Créer les routeurs, les domaines et les projets · installation (l'IA)
  6. Vérifier le workspace · installation (l'IA)
—
rangement
operations · routine, chaque nuit à 2 h ; ou à la demande
  1. Archiver les points du jour cochés ou vieux de plus de 7 jours · rangement (l'IA)
  2. Écrire une fiche pour le texte brut, les liens et les fichiers sans en-tête · fiche · ce que dit la fiche (l'IA)
  3. Donner ses métadonnées à chaque élément ; ranger.py le range · classer · le type, le domaine, le statut, le projet ; dans le doute, une question pour la journée (l'IA)
  4. Écrire le point du jour · rangement · ce qui mérite ton attention (l'IA)
  5. Répondre aux questions en attente · classer · chaque réponse, ou « plus tard » (toi)
  6. Lire le point du jour · valider, corriger ou cocher (toi)
—
