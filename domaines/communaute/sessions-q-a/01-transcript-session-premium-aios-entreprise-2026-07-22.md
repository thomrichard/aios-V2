## Compte rendu synthétique

**Fil rouge :** comment passer d'un AIOS *personnel* à un AIOS *d'entreprise*, et où placer la frontière.

**3 idées fortes :**
- **La bonne ligne de partage, ce n'est pas perso/pro, c'est individuel/collectif.** Ton poste = tes process à toi (routine, veille). Les serveurs de la boîte = le savoir de l'entreprise (procédures, études de prix). On mélange perso et pro à titre individuel, mais pas l'individuel et l'entreprise.
- **Le nerf de la guerre, c'est le coût des tokens.** D'où un système portable : forfait aujourd'hui, LLM local (Gemma) ou serveur (Mac mini / PC IA à demeure) demain, sans être captif.
- **Indexer plutôt que tout stocker.** Vault léger (markdown + index qui pointent), on branche Graphify pour interroger les gros volumes à ~0 token.

**Sujets balayés :** accès distant (Tailscale, sessions Claude Code cloud pour piloter le PC depuis le téléphone) ; capture mobile → inbox (vocal transcrit, durée de vie 7 jours) ; entretien du vault (liens orphelins, infobésité) ; Cowork/Codex vs Claude Code pour brancher les outils.

**Questions ouvertes :** index long vs sous-index (qu'est-ce qui coûte le moins à l'IA ?) ; audit de complétude d'un AIOS (procédure CAPE) ; cas de Robin — faire capitaliser ses collègues de chantier via GitHub + agent IA.
