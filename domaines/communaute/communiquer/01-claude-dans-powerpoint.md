# Claude dans POWERPOINT

J'ai testé Claude directement dans PowerPoint — et franchement, je ne m'y attendais pas à ce niveau.

J'en ai fait une vidéo complète : du fichier brut à la présentation finale, pas à pas.

Et voici les 4 prompts que j'utilise — copie-les et adapte les crochets à ton sujet 👇

---

**Prompt 0 — Brief d'analyse (dans Claude web, avant d'ouvrir PowerPoint)**

```
Je vais créer une présentation sur [sujet].
Comment un cabinet de conseil de haut niveau présenterait-il ce type d'analyse ?
Quels axes couvrir, quelle structure adopter, quels types de conclusions mettre en avant ?
Donne-moi un cadre d'analyse en 5-7 points.
```

---

**Prompt 1 — Structure et plan (dans Claude PowerPoint)**

```
Tu es expert en création de présentations professionnelles.

Contexte : [qui tu es + ce que tu présentes + à qui]
Objectif : [ce que l'audience doit comprendre / décider / ressentir]
Données : [coller les données ou joindre le fichier]
Type d'analyse souhaité : [coller le cadre du Prompt 0]

Première étape : construis le plan.
Nombre de slides, titre de chaque slide, 2-3 points clés par slide.
Ne génère pas encore les slides — je veux valider le plan d'abord.
```

---

**Prompt 2 — Génération des slides (dans Claude PowerPoint)**

```
Le plan est validé. Génère maintenant les slides en respectant
exactement le template de ce fichier.

Contraintes :
- 1 idée par slide
- Titres courts (5 mots max), formulés comme des affirmations
- Maximum 3 éléments par slide
- Commence par un slide de couverture avec titre accrocheur
- Termine par un slide de conclusions avec 3 points clés
```

---

**Prompt 3 — Relecture côté client (dans Claude web, avec le PDF exporté)**

```
Positionne-toi en tant que destinataire de ce document.
Tu reçois cette présentation. Fais-en un débrief complet et objectif :
- Ce qui te convainc
- Ce qui te laisse sceptique ou ce qui manque
- Les 3 modifications prioritaires pour rendre ce deck plus percutant

Tu trouveras également le dataset à l'origine de cette présentation.
Vérifie s'il n'y a pas d'incohérence entre les données et le contenu.
```
