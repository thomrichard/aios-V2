# ⚡ Jour 6 — Make, connecte tes outils

**C'est quoi Make ?** Make est un outil d'automatisation visuelle. Tu connectes des applications entre elles avec une logique simple : quand X se passe, fais Y. Sans coder.

**Pourquoi Make ?** Parce que les outils seuls ne suffisent pas. C'est quand ils se parlent entre eux que la magie opère. Make est le chef d'orchestre de tes systèmes.

**⚡ Défi du jour** Construis ton premier scénario : Airtable → Email.

1. Crée un compte Make
2. Crée un nouveau scénario
3. Module 1 : Airtable — déclenche quand une nouvelle ligne est ajoutée dans ta base Projets
4. Module 2 : Email — envoie-toi une notification avec le nom du projet
5. Ajoute une ligne dans Airtable et regarde l'email arriver

Poste un screenshot de ton scénario dans la communauté.

Tu viens de créer ton premier système automatisé. Demain on assemble tout.
