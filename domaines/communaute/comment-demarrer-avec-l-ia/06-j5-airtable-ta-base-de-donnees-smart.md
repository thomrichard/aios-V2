# 🗄️ J5 — Airtable, ta base de données SMART

**C'est quoi Airtable ?** Airtable, c'est Excel qui a rencontré une base de données. Tu organises tes informations en tables, tu les relies entre elles, et tu les visualises comme tu veux. C'est l'outil de base de presque tous les systèmes qu'on construit dans Club Smart.

**Pourquoi Airtable ?** Parce que sans base de données, tes automatisations n'ont nulle part où stocker l'information. Airtable est le point de départ de presque tous les systèmes intelligents.

**⚡ Défi du jour** Construis ta première base "Projets personnels".

1. Crée une table Projets avec nom, statut, deadline
2. Crée une table Tâches et relie-la à ta table Projets
3. Passe ta table Tâches en vue Kanban
4. Ajoute ta table Projets en vue Calendar sur les deadlines
5. Poste un screenshot de ta base dans la communauté

Tu viens de construire quelque chose qu'Excel ne peut pas faire.
