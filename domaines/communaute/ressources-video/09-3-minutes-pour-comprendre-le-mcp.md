# 3 minutes pour comprendre le MCP

Vidéo : https://www.youtube.com/watch?v=8myDPCnV4y4

_Vidéo du 1er avril 2026_

## De quoi elle parle

Le MCP (Model Context Protocol) est un standard qui permet à n'importe quel outil de se connecter à ton IA de la même façon. La vidéo explique ce qu'il change, et comment brancher un connecteur dans Claude.

## Les points clés

- Avant, chaque usage demandait son scénario Make, n8n ou Zapier, ou un développement sur l'API.
- Avec le MCP, une seule connexion donne à Claude toutes les actions autorisées par l'outil.
- Dans Claude : les connecteurs déjà proposés, ou un connecteur personnalisé à partir de l'adresse d'un serveur MCP.
