# Comment j'ai automatisé ma vie avec un AIOS

Vidéo : https://www.youtube.com/watch?v=FwnIB-RbC-E

_Vidéo du 7 juillet 2026 · masterclass de 1 h 17_

## De quoi elle parle

La masterclass complète pour construire ton AIOS : un système d'exploitation IA personnel, construit autour de ton contexte, sans être développeur. Pilier par pilier, sur mon vrai système.

## Les points clés

- Le cadre CAPE : Contexte, Accès, Production, Entretien.
- Le contexte : les trois fichiers de base et le second cerveau rangé en IPCCRA, avec l'arbre de décision pour savoir où ranger chaque information.
- L'accès : brancher tes outils (mails, agenda…) avec les API, les MCP et le CLI.
- La production : les skills qui produisent à ta façon.
- L'entretien : les automatisations, l'audit hebdo en cinq questions et la sauvegarde sur GitHub.

## Les ressources

- **La carte CAPE** : le cadre en une page, les quatre questions auxquelles tout système IA personnel doit répondre. [Ouvrir la carte](https://www.thomrichard.com/masterclass-aios-ressources/pack/carte-cape/).
- **Le guide setup, pas à pas** : douze pages avec captures pour installer Claude Code, ouvrir ton vault et poser les fondations. [Ouvrir le guide](https://www.thomrichard.com/masterclass-aios-ressources/pack/guide-setup/).
- **La skill aios-bootstrap** : un fichier à donner à Claude Code ; il t'interroge, puis construit ton second cerveau complet. [Voir sur GitHub](https://github.com/thomrichard/aios-bootstrap).
