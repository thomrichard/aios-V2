# Etape 2 - Obtenir l'api nécessaire

Vidéo : https://youtu.be/_lWwgQg1b_k

---

🎬 **Titre résumé de la vidéo** : Comment créer un compte RapidAPI, trouver l'API YouTube (YT API) et générer la clé API pour une automatisation

🧠 **Ce que la vidéo vous apprend concrètement** :

- Créer un compte sur RapidAPI (inscription via Google).
- Identifier et sélectionner l'API adaptée (YT API / YouTube API) sur la marketplace RapidAPI.
- Repérer les endpoints utiles (videos, shorts, channels, posts).
- Choisir un plan (plan gratuit) et comprendre la facturation gérée par RapidAPI.
- Générer et récupérer la clé API à utiliser ensuite dans une automatisation.

🔧 **Outils utilisés** :

- RapidAPI (marketplace d'APIs)
- YT API (YouTube API) disponible via RapidAPI
- Compte Google (pour la connexion/inscription)

⚙️ **Modules Make (ou autres outils) utilisés** :

- Déclencheur : aucun module Make mentionné dans le transcript (aucun trigger spécifié).
- Modules principaux : aucun module Make ou action d'automatisation précis n'est mentionné dans le transcript. Le contenu se limite à l'utilisation de RapidAPI pour sélectionner l'API et récupérer la clé.

🔁 **Workflow présenté** :

- Aller sur [rapidapi.com](http://rapidapi.com) et cliquer sur "Sign up".
- S'inscrire / se connecter (exemple : connexion via un compte Google).
- Parcourir la marketplace et rechercher l'API souhaitée → sélectionner "YT API" (YouTube API).
- Vérifier que l'API propose les endpoints nécessaires : informations sur vidéos, shorts, chaînes (channels), posts.
- Souscrire au plan (choix du plan gratuit) — noter que la facturation est gérée par RapidAPI.
- Récupérer la clé API fournie par RapidAPI : c'est cette clé qu'il faudra utiliser ensuite dans l'automatisation.
