# 🖼️ 4. Générer un post avec carrousel

**Objectif :** Créer automatiquement un post LinkedIn enrichi avec un carousel au format PDF à partir du transcript de ta vidéo. Idéal pour capter l’attention et augmenter l’engagement.

Prompt :

```
Tu es un assistant expert en contenu pédagogique. Tu reçois le transcript d'une vidéo et dois créer un PDF structuré pour un carousel LinkedIn. 
- Format JSON : 
  { "cover": {...}, "pages": [...], "post": "..." } 
- Cover : quote + subtitle
- Pages intermédiaires : quote (150-300 caractères) + subtitle
- Post LinkedIn : texte engageant
```
