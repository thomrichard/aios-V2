# Base de données de prompts de génération d'images

[=> Accéder à la base de données ](https://zeliotin.gumroad.com/l/1000Prompts)

Cette base de données est une collection de styles artistiques et de mots clés d'ambiance qui vous permettront de transformer vos images générées par IA en véritable art digital.

Les styles artistiques sont un moyen puissant de transformer vos images d'IA. L'IA connaît tous ces styles artistiques, mais peut-être pas vous ! Gagnez du temps de recherche et atteignez tout de suite un **résultat époustouflant**!

Dans cette base de données, vous verrez le rendu des prompts afin de vous en inspirer, et pas uniquement une liste de phrases comme on peut le voir sur d'autres produits. Vous pouvez également changer le type de vue pour une meilleure lisibilité:

![null](https://public-files.gumroad.com/hde8berpkn1ywcynil3ixg3qj1g0)

![null](https://public-files.gumroad.com/mrm5pa0b1i86cwcu3g6xvoom0xvh)

> exemple de prompt :   
splash art, alcohol ink, creepy, detailed painting of fashion by hanae mori, adorable cute green skin zombie missing some teeth, dark fantasy, portrait, voodoo ambience, glowing, UHD, vivid colors, Arthur Rackham, Dr. Seuss, Norman Rockwell, magic, digital illustration, luminism, rim lighting, mysterious  
Prompt négatif :   
noisy, blurry, distorted, out of focus, extra limbs, poorly drawn face, poorly drawn hands  
modele :   
SDXL_0_9 (avec alchemy)  
  
Voici le rendu :

![null](https://public-files.gumroad.com/w3xy7ublo4y5ps37h2jtww7ejd7z)

En changeants quelques mots dans le prompt, vous pouvez obtenir** un style identique pour un résultat totalement inédit!**

La base de données contient des exemples d'images générés avec ces prompts, afin de vous inspirer. Une fois que vous avez choisi un style, vous n'avez plus qu'à le copier, et à le coller dans Lenoardo (ou tout autre générateur d'images) et à l'adapter en fonction de votre propre projet!
