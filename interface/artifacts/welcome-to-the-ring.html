SM4RT Agentic OS · Livrable d’exemple

Bienvenue dans l’anneau

Tu viens de cliquer sur une boule. Tout le principe est là : chaque fichier HTML que ton agent dépose dans le dossier des livrables devient une boule comme celle-ci, un marque-page permanent et cliquable qui tourne autour du centre de ton OS.

Trois raisons pour lesquelles ça sert vite :

  1. Tes rapports se retrouvent. Une note de recherche d’il y a trois semaines est à un clic, sans fouiller les dossiers. Appuie sur / dans l’OS pour rechercher parmi toutes les boules.
  2. Les exécutions de skills s’inscrivent seules. Chaque exécution en autonomie lancée depuis le deck de skills laisse ici son rapport, automatiquement.
  3. Ton agent garde l’habitude. RING.md contient un extrait à copier-coller dans le fichier d’instructions de ton agent. Ensuite, tout ce qu’il construit arrive ici sans que tu le demandes.

Cet exemple et ses deux voisins ne sont que des fichiers dans artifacts/ : supprime-les quand tu veux.
