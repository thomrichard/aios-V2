# Idées

Une idée, c'est un truc que Thomas aimerait peut-être creuser un jour, sans engagement. Elle a le type `idee` (`systeme/metadonnees.md`) et vit dans son domaine : `domaines/<domaine>/<slug>.md`. Son champ `ressortir` dit dans quel contexte la rappeler, pas une date.

## Les règles

1. Le test, dans l'ordre : ça nourrit quelque chose qui existe ou qui revient (newsletter, vidéo, projet actif, offre) → ça va là-bas (un `sujet` ou une tâche) ; je veux m'y mettre maintenant, avec une prochaine étape → c'est un projet ; sinon → c'est une idée. Dans le doute, une seule question.
2. À la capture : aucune question, pas de filtre des objectifs.
3. « Creuse cette idée » : `grill-me` court (5 questions au plus), écrit dans la fiche, statut `en-reflexion`.
4. Quand on démarre un projet, un contenu ou une réflexion d'offre : `grep -r "^ressortir:" domaines/` ; si une idée colle, dis-le en une ligne.
5. Jamais d'idées dans le point du jour. « Tri des idées » : celles au statut `notee` depuis plus de 3 mois, en un lot.

## Les idées

Une ligne par idée, ajoutée quand elle est notée, mise à jour quand son statut change : `- [<titre>](../domaines/<domaine>/<slug>.md) · <domaine> · <statut>`.
